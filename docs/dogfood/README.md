# Harness dogfood evidence

This directory records real use of Harness. Reports should include failures,
ignored features, and manual workarounds—not only successful outcomes.

Copy `TEMPLATE.md` for each project or sustained evaluation period. Keep raw or
sensitive datasets outside the repository; record stable fingerprints and source
descriptions instead.
